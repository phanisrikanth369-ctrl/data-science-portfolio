Titanic Survival Prediction

📌 Project Overview

This project uses Machine Learning to predict whether a passenger survived the Titanic disaster based on passenger information.

🎯 Objective

The main objective of this project is to build a classification model that predicts passenger survival.

📊 Dataset

The dataset contains information about Titanic passengers, including:

- Passenger Class
- Gender
- Age
- Number of Siblings/Spouses
- Number of Parents/Children
- Fare
- Embarkation Port
- Survival Status

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

🔄 Project Workflow

1. Load the dataset
2. Understand the data
3. Handle missing values
4. Remove unnecessary columns
5. Convert categorical variables
6. Perform exploratory data analysis
7. Split the data into training and testing sets
8. Train the Logistic Regression model
9. Make predictions
10. Evaluate the model

🤖 Machine Learning Model

Logistic Regression

Logistic Regression was used as the classification algorithm to predict whether a passenger survived.

📈 Model Evaluation

The model was evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

🔍 Key Insights

- Passenger demographic information can be used for survival prediction.
- Passenger class and gender are important features in the dataset.
- Data preprocessing is required before applying the machine learning model.
- Logistic Regression provides a baseline classification approach.
